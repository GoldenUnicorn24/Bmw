# OpenHiggsfield Mobile Android

Independent, unofficial Android companion that loads https://www.openhiggsfield.ai/ in a secure native WebView. Not a source port or official Higgsfield AI client. No third-party project code is bundled. Requires internet, an API key and model credits where applicable. Supports native media selection and HTTP(S) downloads.

Build using Java 17 / Gradle 8.11.1 / Android SDK 35:
```sh
cd openhiggsfield-android
gradle assembleDebug
```
The APK is at app/build/outputs/apk/debug/app-debug.apk.
